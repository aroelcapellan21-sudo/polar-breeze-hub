# Fotos — Productos (catálogo BON)

Fotos de los productos del catálogo, organizadas por tipo. Sirven para fichas de
producto, material de venta, y referencias visuales en las apps.

## Subcarpetas

- `paletas/` — fotos de paletas (choco crema, bonice, frambuesa, uva, naturales, magnum…).
- `helados/` — fotos de helados (copas, cajitas, pintas, mordisco…).

## Convenciones

- **Formato:** `.jpg` / `.jpeg` / `.png`.
- **Nombre del archivo = nombre del producto** lo más parecido al catálogo (`PRECIOS`/`PALETAS`/`HELADOS`
  en `polar-breeze-final.html`) para poder casarlas por nombre más adelante.
- Una foto por producto, fondo limpio de preferencia.
