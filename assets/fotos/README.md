# assets/fotos — Fotos y capturas por área

Carpeta de imágenes del sistema **Polar Breeze Hub**, organizada por las 4 áreas/roles.
Usar estas imágenes para documentación, manuales de usuario, material de capacitación
y referencias visuales del diseño aprobado.

## Estructura

| Subcarpeta | Área / rol | Qué va aquí |
|------------|------------|-------------|
| `hub/`         | Hub Admin (Oliver, dueño) | Capturas del dashboard, KPIs, gráficos y gestión |
| `despachador/` | App Despachador           | Capturas del flujo de despacho + fotos del Cuarto Frío |
| `encargado/`   | App Encargado / Supervisor | Capturas de lotes, stock, picking, reposición + fotos del loker |
| `chofer/`      | App Chofer                | Capturas de la consulta de inventario del día |

## Convenciones

- **Formato:** preferir `.png` para capturas de pantalla y `.jpg` para fotos reales.
- **Nombres:** descriptivos en minúsculas con guiones, ej. `stock-encargado-movil.png`,
  `cuarto-frio-real.jpg`. Incluir `-movil` / `-tablet` / `-desktop` si aplica.
- **No subir** fotos con datos sensibles reales (nombres/precios) si son para material público.
- Cada subcarpeta tiene su propio `README.md` con el detalle de lo que se espera.
